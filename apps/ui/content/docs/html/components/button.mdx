## Full CSS

Here's the complete CSS for all button variants:

```css
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 0.5rem;
  white-space: nowrap;
  border-radius: 0.5rem;
  font-size: 0.875rem;
  font-weight: 500;
  padding: 0.5rem 1rem;
  min-height: 2rem;
  border: 1px solid transparent;
  cursor: pointer;
  transition: all 150ms ease;
  background-color: #18181b;
  color: white;
}

.btn:hover {
  background-color: #27272a;
}

.btn:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

/* Variants */
.btn-primary {
  background-color: #2563eb;
}
.btn-primary:hover {
  background-color: #1d4ed8;
}

.btn-secondary {
  background-color: #f4f4f5;
  color: #18181b;
}
.btn-secondary:hover {
  background-color: #e4e4e7;
}

.btn-outline {
  background-color: transparent;
  border-color: #e4e4e7;
  color: #18181b;
}
.btn-outline:hover {
  background-color: #f4f4f5;
}

.btn-ghost {
  background-color: transparent;
  color: #18181b;
}
.btn-ghost:hover {
  background-color: #f4f4f5;
}

.btn-destructive {
  background-color: #dc2626;
}
.btn-destructive:hover {
  background-color: #b91c1c;
}

/* Sizes */
.btn-sm {
  min-height: 1.75rem;
  padding: 0.25rem 0.625rem;
  font-size: 0.75rem;
}

.btn-lg {
  min-height: 2.5rem;
  padding: 0.5rem 1.25rem;
  font-size: 1rem;
}
```
